# Venture Beyond (web subsets)

RaidGuild's open-source display family, used by the landing pages through `src/lib/fonts.ts`.

| File | CSS family / style |
|---|---|
| `VentureBeyond-Latin.woff2` | `Venture Beyond`, normal (Upright) |
| `VentureBeyond-Italic-Latin.woff2` | `Venture Beyond`, italic |
| `VentureBeyond-Retalic-Latin.woff2` | `Venture Beyond Retalic`, normal (10° reverse slant) |

These are variable fonts with weight 100–900 and width 62–125. The subsets cover Basic Latin,
Latin-1, Latin Extended-A, combining marks, punctuation, currency and common symbols.

**Source.** The files are copied unchanged from
[`raid-guild/brand`](https://github.com/raid-guild/brand) `public/fonts/venture-beyond/` at
commit `6e3ed06`. `SHA256SUMS` pins them, so check them with `shasum -a 256 -c SHA256SUMS`.

Don't edit or regenerate them here. The build pipeline and the complete distribution are in the
brand repository under `typography/venture-beyond/`.
